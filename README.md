# Task 2: Exploratory Data Analysis (Ethiopia Climate Data)

This project performs data profiling, cleaning, and exploratory data analysis (EDA) on Ethiopia's climate dataset covering the period 2015–2026.

## Key Work Done
- Loaded Ethiopia climate dataset (2015–2026)
- Replaced missing values (-999 → NaN)
- Checked and removed duplicate records
- Created datetime column from YEAR and DOY
- Extracted monthly features for seasonal analysis
- Generated summary statistics for all variables
- Performed outlier detection using Z-scores
- Handled missing values appropriately
- Conducted time series analysis on temperature and rainfall
- Analyzed correlations between climate variables
- Created visualizations (line plots, scatter plots, heatmaps)

## Key Insights
- Temperature shows clear seasonal patterns across 2015–2026
- Rainfall is highly seasonal with distinct wet and dry periods
- Strong relationship exists between temperature, humidity, and rainfall

## Output
Cleaned dataset and visual analysis stored in the notebooks directory.
